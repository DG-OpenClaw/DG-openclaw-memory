# Playbook

## 1. Segmentation / ICP
Capture only what changes strategy:
- company size or consumer type
- budget sensitivity
- urgency / job-to-be-done
- switching cost
- buying trigger

## 2. Competitor buckets
Use buckets so analysis stays sane:
- direct competitors
- adjacent alternatives
- substitute behaviors
- do-nothing option

## 3. Messaging teardown rubric
For each homepage / landing page, inspect:
- headline: what promise is made?
- subhead: who is it for?
- proof: logos, testimonials, numbers, case studies
- CTA: demo, signup, contact, buy
- tone: premium, practical, technical, playful
- objection handling: security, pricing, migration, setup, ROI

## 4. Positioning gaps
Look for gaps in:
- audience specificity
- speed / ease claims
- proof density
- pricing clarity
- integration ecosystem
- local language / market adaptation
- trust / compliance

## 6. Confidence labels
Use simple labels:
- high: confirmed on primary sources
- medium: plausible, partial evidence
- low: weak evidence / inference heavy
