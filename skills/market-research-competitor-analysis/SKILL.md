# Market Research + Competitor Analysis

Use this skill for a marketing-oriented agent such as 魔亜懸ゴリ蔵.

## Default outputs
Choose the smallest useful output:
- **Quick scan**: 3-5 competitors, core positioning, obvious gaps
- **Comparison table**: competitor, audience, offer, pricing, strengths, weaknesses
- **Messaging teardown**: headline, promise, proof, CTA, tone
- **Action memo**: what to test next

## Workflow
1. Clarify the target:
   - product / category
   - region / language
   - target customer
   - direct vs indirect competitors
2. Gather evidence from official sites first.
3. Then use reviews, launch pages, docs, pricing pages, app stores, social proof, and third-party writeups.
4. Separate **facts** from **inference**.
5. End with concrete implications:
   - where to differentiate
   - what message angle to test
   - what feature gap matters
   - what not to copy

## Minimum comparison frame
For each competitor, try to capture:
- name
- target customer
- core promise
- main features / offer
- pricing / packaging
- trust signals
- weaknesses / risks
- strategic note

## Guardrails
- Prefer primary sources over SEO sludge.
- Do not invent pricing or features.
- If evidence is thin, say confidence is low.
- Keep outputs compact and decision-friendly.
- For Discord, avoid markdown tables if the result will be posted directly; use bullets instead.

## Handy structure
Use this when the user asks for a usable answer fast:
1. Market snapshot
2. Top competitors
3. Positioning gaps
4. Recommendations
5. Confidence / unknowns
