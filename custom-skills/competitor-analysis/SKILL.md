# Competitor Analysis

Map the competitive landscape in a way that supports action.

## Workflow

1. Define the focal company or product.
   - State the target company/product and market context.
2. Identify competitor types.
   - Direct competitors
   - Indirect competitors
   - Substitute solutions
3. Compare on the dimensions that matter for the use case.
   - Positioning
   - Target customer
   - Offer / feature set
   - Pricing model
   - Distribution / go-to-market
   - Proof points, brand, hiring, partnerships, momentum
4. Distill implications.
   - Where the focal player is strong
   - Where it is exposed
   - White-space opportunities

## Default output structure

- Executive summary
- Competitor set and selection logic
- Comparison table or bullet comparison
- Positioning differences
- Strengths / weaknesses by rival
- Strategic implications
- Recommended next moves
- Sources

## Quality bar

- Avoid comparing on features alone; include distribution, messaging, and customer fit.
- Note when data is missing instead of guessing.
- Distinguish direct threats from adjacent noise.
- Prefer a small accurate competitor set over a bloated list.
