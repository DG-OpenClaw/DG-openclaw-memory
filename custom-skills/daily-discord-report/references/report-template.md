# Daily Discord Report Template

Use this as the default output shape.

## Template

**日報 YYYY-MM-DD (JST)**

**今日のサマリー**
- ...
- ...
- ...

**詳細ログ**
- HH:MM - ...
- HH:MM - ...
- HH:MM - ...

**タスク進捗**
- Task A — 完了 — 次: なし
- Task B — 進行中 — 次: ...
- Task C — 保留 — 次: ...

**セキュリティ / ヘルスチェック**
- OpenClaw: OK / Issue / 未確認
- Git / workspace: OK / Issue / 未確認
- その他: ...

**明日の優先事項**
- ...
- ...
- ...

## Notes

- If exact times are unavailable, omit timestamps and group by topic.
- If there are blockers, add one bullet under the relevant section instead of creating extra ceremony.
- If the report is interim, write `暫定版` in the title.
