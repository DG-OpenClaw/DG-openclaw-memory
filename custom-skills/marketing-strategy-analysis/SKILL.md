# Marketing Strategy Analysis

Run analysis in this order:
1. Macro environment
2. Market structure and competition
3. Target service/company
4. Customer and segment understanding
5. Emotional decision drivers
6. Funnel and retention strategy
7. Customer journey and next actions

Do not dump frameworks mechanically. Use only the minimum set that produces a decision-ready answer.

## Default workflow

1. Define the analysis target.
   - Clarify company/product/service, geography, customer type, and goal.
   - If details are missing, state working assumptions.
2. Run macro analysis.
   - Use market trend analysis first.
   - Add PEST when external change matters.
3. Run market structure and competitor analysis.
   - Use 3C as the core frame.
   - Add competitor mapping or substitute analysis when position is unclear.
4. Run target/service analysis.
   - Use SWOT and USP.
   - Add 4P/4C if offer design, pricing, or communication matters.
5. Run customer analysis.
   - Use STP and persona design.
   - Use JTBD when motivation is deeper than surface demand.
6. Run emotional and behavioral analysis.
   - Identify emotional triggers, anxieties, expectations, and trust points.
   - Map purchase funnel and repeat/retention funnel.
7. Build the output.
   - Synthesize into strategy, journey, KPI ideas, and prioritized next moves.

## Default analysis set

Use these by default unless the task is very narrow:
- Market trend analysis
- 3C
- SWOT
- STP
- USP hypothesis
- Persona
- Emotional trigger analysis
- Purchase funnel analysis
- Retention / repeat funnel analysis
- Customer journey

## Optional analysis frames

Use only when relevant:
- PEST
- Competitor mapping
- Substitute analysis
- 4P/4C
- JTBD
- KPI design

## Output rules

- Separate facts, estimates, and hypotheses.
- Include both macro and micro findings unless the user explicitly wants only one side.
- Tie emotional analysis to behavior, not vague adjectives.
- Do not stop at analysis; end with strategic implications.
- For every research-style output, include citations with both the site name and the source URL.
- Attach citations inline or directly below the relevant claim when practical.
- End with a `Sources` section that repeats each cited source as `Site name — URL`.
