# Concrete Analysis Methods

## PEST method
1. Gather 3-8 recent external signals.
2. Group each signal into P/E/S/T.
3. For each item, state:
   - what changed
   - why it matters
   - effect on buyer behavior
   - strategic implication
4. End with the top 3 external forces.

## Market trend method
1. Define the market boundary.
2. Gather size/growth evidence if available.
3. If hard data is weak, use directional signals:
   - search demand
   - media coverage
   - competitor launches
   - funding / hiring / partnerships
4. State growth drivers, constraints, and likely near-term direction.

## 3C method
1. Customer:
   - identify main pains, desired outcomes, buying criteria, objections
2. Competitor:
   - identify direct, indirect, and substitute solutions
3. Company:
   - identify strengths, assets, delivery model, credibility
4. Synthesize the strategic overlap:
   - where need is strong
   - where competitors are weak
   - where company can win

## Competitor mapping method
1. Pick 2 axes that actually affect choice.
2. Place 3-7 competitors.
3. Explain each placement briefly.
4. Identify:
   - crowded space
   - weakly served space
   - likely best position for the target company

## Substitute analysis method
1. Ask what customers do if they do not buy.
2. List alternatives.
3. Compare each on:
   - cost
   - effort
   - familiarity
   - emotional comfort
   - switching friction
4. Treat status quo as a real competitor.

## SWOT method
1. Pull internal points from company/service facts.
2. Pull external points from market and competitor findings.
3. Build the grid.
4. Convert the grid into:
   - offensive moves
   - defensive moves
   - weaknesses to fix
   - threats to watch

## STP method
1. Segment by meaningful variables:
   - industry / size / lifecycle / use case / pain intensity / buyer maturity
2. Score segments on:
   - demand strength
   - accessibility
   - profitability
   - repeat potential
   - strategic fit
3. Select primary and secondary targets.
4. Define position in one sentence.

## 4P/4C method
1. Document the current 4P.
2. Translate each one into the customer-side 4C.
3. Check where seller intent and customer reality diverge.
4. Highlight offer, pricing, access, or message gaps.

## USP method
1. List product/service strengths.
2. Filter out generic claims.
3. Keep only claims that are:
   - valuable
   - differentiated
   - believable
4. Turn the result into a concise USP statement.
5. Add proof points and ideal audience.

## JTBD method
1. Define the situation that triggers demand.
2. Define the progress the customer wants.
3. Separate:
   - functional job
   - emotional job
   - social job
4. Connect the job to buying hesitation and success criteria.

## Persona method
1. Select one priority segment.
2. Define a realistic role/person.
3. Fill:
   - background
   - problem context
   - goals
   - information behavior
   - comparison criteria
   - emotional blockers
   - decision trigger
   - retention trigger
4. Avoid demographic-only personas.

## Emotional trigger method
1. For each funnel stage, define:
   - customer state
   - dominant emotion
   - source of that emotion
   - what reduces friction
   - what increases motivation
2. Translate emotion into message and offer implications.

## Purchase funnel method
For each stage, specify:
- customer state
- emotion
- question / objection
- needed information
- effective message
- effective channel
- KPI idea

## Retention / repeat method
For each stage after purchase, specify:
- what proves value
- what causes drop-off
- what builds habit
- what builds trust and satisfaction
- what drives repeat / upsell / referral

## Customer journey method
1. Start with funnel stages.
2. Add behavior, touchpoints, thoughts, emotions, friction, content, actions, KPI.
3. Highlight where the experience breaks.
4. Prioritize the few interventions with the highest impact.
